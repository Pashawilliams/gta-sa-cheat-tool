# Grove Codes

**Русскоязычный помощник для чит-кодов GTA: San Andreas Classic. Windows 10/11 x64.**

Тёмный интерфейс с зелёным акцентом, 88 записей, поиск, категории, локальное избранное, копирование и отправка кода в игру. Это **отдельная программа**, не меню внутри GTA и не memory trainer. CLEO, ASI Loader, .NET и Python для запуска EXE не нужны.

## Скачать и запустить

Открой **Releases**, скачай `GroveCodes.exe` либо ZIP. Не клади EXE в папку игры: запускай из любой папки. Установка не требуется.

1. Сделай отдельное сохранение GTA. Запусти классическую одиночную игру и загрузи сохранение.
2. Запусти `GroveCodes.exe` обычным пользователем, как и игру.
3. Найди код, нажми **Отправить в GTA →** и подтверди предупреждение.
4. Программа попробует переключиться в GTA. За 3 секунды вернись в игровой процесс, закрой меню и выбери английскую раскладку.
5. Не нажимай клавиши, пока вводится код. Каждая буква удерживается 100 мс, затем отпускается; между буквами — 100 мс.
6. Проверь игровое уведомление о срабатывании. Программа отправляет клавиши, но **не может подтвердить активацию**.

**Esc** отменяет ввод. Потеря фокуса GTA также отменяет его. Уже отправленные буквы не удаляются. Повторяй код только после возвращения в нормальный игровой процесс. Не все читы обратимы повторным вводом; безопасный способ сброса — загрузить чистое сохранение.

Кнопка «Копировать» копирует текст для справки. Обычная GTA не поддерживает вставку кодов через Ctrl+V: при проблемах с автоматическим вводом набери код вручную.

## Совместимость и ограничения

- Требуется **64-битная Windows 10/11**; сама классическая игра может быть 32-битной.
- Ищется видимое окно процесса `gta_sa.exe` или `gta-sa.exe`. При нескольких экземплярах выбирается первое подходящее окно.
- Не предназначено для Definitive Edition, SA-MP, MTA или других сетевых режимов. Наличие мультиплеерных модов автоматически не определяется.
- Проверки версий и чтения состояния игры нет. Пауза, кат-сцены, модификации ввода и некоторые сборки могут мешать активации.
- Если переключение окна не сработало, вернись в GTA самостоятельно в течение 3 секунд или повтори отправку. Оконный режим может быть удобнее.
- Windows может блокировать ввод, если GTA запущена с повышенными правами. Предпочтительно запускать обе программы **без прав администратора**. Не отключай защиту Windows.
- База содержит 88 распространённых кодов/эффектов классической версии, а не все текстовые синонимы и не новые коды Definitive Edition. Полнота для каждой модифицированной сборки не гарантируется.
- Читы на беспорядки и пешеходов могут мешать миссиям. Не перезаписывай основное сохранение.

## Безопасность и приватность

Исходники открыты. В программе нет сетевых запросов, телеметрии, загрузки дополнительных файлов, автообновления, автозапуска, DLL-инъекций или записи в память игры. `OpenProcess` используется только с `PROCESS_QUERY_LIMITED_INFORMATION`, чтобы узнать имя EXE. Ввод — стандартный Windows `SendInput` со скан-кодами. Низкоуровневых клавиатурных хуков нет; Esc и модификаторы проверяются только во время отправки.

Единственный собственный файл настроек: `%LOCALAPPDATA%\GroveCodes\favorites.ini`. Удаление программы и этой папки полностью удаляет тул.

**EXE не подписан цифровым сертификатом.** Windows SmartScreen может предупредить о неизвестном издателе. Это не антивирусная сертификация: независимо проверь файл своей защитой и сравни SHA-256. Не отключай антивирус ради запуска.

## Статус проверки

- Успешная кросс-компиляция MinGW-w64 в Windows x64 PE.
- Автопроверка структуры базы, уникальности 88 основных кодов и формата ASCII A–Z.
- Проверка импортов EXE: только GDI32, KERNEL32, msvcrt и USER32.
- **Запуск на Windows, отправка в реальную GTA и антивирусное сканирование в среде сборки не выполнены.** Релиз предназначен для первичной проверки пользователем; 100% совместимость не заявляется.

См. [TESTING.md](TESTING.md) для проверки на компьютере с игрой.

## Сборка из исходников

На Debian/Ubuntu:

```sh
sudo apt-get install g++-mingw-w64-x86-64-posix python3
bash build.sh
```

Результат: `release/GroveCodes.exe`, контрольная сумма: `release/SHA256SUMS.txt`. Сборка статически включает runtime GCC/C++; дополнительные нестандартные DLL не нужны. Иконка включена в исходники. Для изменения базы отредактируй `cheats.tsv`; `generate_data.py` пересоздаёт `src/cheats.h`.

Проверка хеша в PowerShell:

```powershell
Get-FileHash .\GroveCodes.exe -Algorithm SHA256
```
